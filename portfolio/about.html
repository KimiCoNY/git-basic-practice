Về Tôi

  • Thiết kế Mobile-First & Responsive Layouts
  • Quản lý mã nguồn với Git & GitHub
  • Tối ưu hóa hình ảnh và tốc độ tải trang
  • Hiểu biết căn bản về UI/UX và thiết kế hệ thống
