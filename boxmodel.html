📊 Công thức tính tổng chiều rộng chiếm dụng (Total Space Width):

Mặc định trong CSS (`box-sizing: content-box`), tổng chiều rộng của khối trên màn hình bao gồm:

Tổng chiều rộng = width + padding (trái + phải) + border (trái + phải) + margin (trái + phải)
  • Width (Nội dung): 200px
  • Padding (Đệm trong): 35px + 35px = 70px
  • Border (Viền): 20px + 20px = 40px
  • Margin (Lề ngoài): 25px + 25px = 50px

➡️ Tổng không gian chiếm dụng: 200 + 70 + 40 + 50 = 360px
